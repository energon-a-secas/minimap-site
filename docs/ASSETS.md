# Minimap, asset production guide

Next steps for replacing placeholders with real art. Everything ships without these; each section upgrades one placeholder in place.

## 1. Character portraits (replaces the SVG silhouette)

The chargen preview (`renderPortrait` in `js/chargen.js`) currently draws an SVG silhouette. The silhouette baseline is now layered (class-colored arch backdrop, rim light, ground shadow, per-class props, idle breathe animation) but it remains the placeholder: the drop-in contract below is unchanged, and the silhouette stays the final fallback. Roster cards reuse a compact variant of the same SVG at 56px, so real art should swap into both spots. Real portraits drop in as images.

**Drop-in contract**

- Path: `assets/portraits/{class}-{sex}-{build}.png` (e.g. `archer-woman-athletic.png`)
- Fallback chain the code should try: exact file -> `{class}-{sex}.png` -> SVG silhouette (keep it forever as the last resort)
- Size: 560x720 (7:9, matches the `.portrait` box), transparent or very dark background, subject lit from the upper left
- Budget: 3 classes x 2 sexes = 6 base images minimum; 18 if build variants feel worth it. Height can stay a CSS transform (scale 0.94 / 1.0 / 1.06), do not render per-height art.

**Image generation prompt template** (works on local SD/Flux models; keep the seed per character so variants stay consistent):

> three-quarter portrait of a {sex} {class-word}, {build} build, {hair} hair, dark fantasy, weathered exile, muted colors, dramatic rim light from upper left, black background, painterly, no text, no watermark

Class words that read well: druid = "wilderness druid with antler talismans and a gnarled staff", archer = "hooded ranger with a recurve bow over the shoulder", mage = "frost mage with a glowing cold orb".

**Style rules**

- Palette must sit on the site tokens: background near `#040714`, one accent per class (druid `#7dbb5e`, archer `#d8c06a`, mage `#7fd4f0`)
- Faces mostly in shadow. This is a parody of a grim game; nobody smiles.
- Export PNG, then squash to under 150 KB each (`pngquant --quality 60-80`)

Wire-up: in `renderPortrait`, attempt `new Image()` load of the exact path, swap into `#portraitBox` on success. Roster cards (`renderRoster`) can reuse the same image at 64px.

## 2. Biome backdrops (optional upgrade over the generated blobs)

`paintBackdrop` (js/render.js) paints random radial blobs and blurs them. It already sells the joke. If real art ever replaces it:

- Path: `assets/biomes/{biome}.jpg` (caverns, wetlands, forest, ruins, crypt)
- Size: 1600x900, heavily out of focus BEFORE export (bake the blur, then the CSS blur doubles it), under 120 KB
- Content: abstract environment shapes only. If you can tell what anything is, it is too sharp.
- Prompt template: "out of focus dark {biome} environment, bokeh, murky, no subject, game screenshot at 144p upscaled, muted {palette words}"
- Wire-up: in `paintBackdrop`, draw the image first, keep the blob pass on top at ~40% alpha for per-seed variation, keep the vignette.

## 3. UI ornaments (the "get fancy" list)

Current HUD is CSS-only. Upgrade order, biggest visual payoff first:

1. **Orb frames**: a gothic metal ring PNG (transparent center, 340x340) laid over each orb; `assets/ui/orb-frame.png`, one asset shared by both orbs, tinted with `filter: hue-rotate` for life vs mana. Add a subtle liquid wobble by animating the fill's `border-radius`.
2. **Skill button plates**: 64x64 stone-slab background with a beveled gold border; replace the flat `.skill` background. States: idle, hover glow, cooldown (already handled by the sweep overlay).
3. **Quest tracker flourish**: a thin horizontal divider SVG (curled line with a center diamond, gold `#c8aa6e`) above the quest title.
4. **Waypoint panel parchment**: dark leather/parchment texture tile behind `.wp-panel`, 256x256 seamless, at 8% opacity.
5. **Boss bar caps**: two small metal end-cap SVGs flanking `.boss-bar__track`.
6. **Class skill icons**: replace the unicode glyphs in `.skill__icon` and chargen cards with 3 custom 24x24 SVGs (thorn burst, arrow through three dots, snowflake ring). Single color `currentColor` so CSS themes them.
7. **Atlas node art**: tiny per-biome emblem (16x16 SVG) inside cleared atlas nodes instead of the checkmark.

All ornament SVGs: stroke-based, `currentColor`, no embedded rasters, so they inherit theme colors.
