# CLAUDE.md: Minimap

Minimap: parody ARPG played entirely on the minimap; procedural biome dungeons, BFS click-to-move, rarity dots, boss telegraphs, atlas progression, level 80→100 grind (minimap.neorgon.com)

**Live:** minimap.neorgon.com · **Port:** 8854

## Run

```bash
make serve
```

Then open http://localhost:8854. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Data

No persisted state: everything lives in memory for the session.

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
